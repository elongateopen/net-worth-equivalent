# 净当量 Net Equivalent

把钱、时间、健康、关系和情绪放进同一张账本，算出一份收入真正可持有的净当量。

一笔账面月入会被六项生活税贴现：注意残留、睡眠与身体、关系、情绪、可持续性、享乐适应。剩下的数字，才是风险调整后的生活结果。

## 怎么用

- 先点情景样本：高压交易员、两年冲刺、稳定专业、共赢系统、双亏内卷
- 三个视图：象限拉扯、完整账单、当量瀑布
- 打开「联动代价」后，加强度会拉动工时、睡眠、关系和情绪
- 恢复空间和冲刺期限是结构杠杆：不必更用力，也能抬高净当量

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

栈：React 19、TanStack Start、Tailwind v4、Zustand。默认不登录、不写数据库。

## 模型是草稿

净当量不是精确的幸福公式。权重和时间轴都可以改。当前校准过的对照：

| 情景 | 账面 | 净当量 | 象限 |
| --- | --- | --- | --- |
| 高压交易员 | 18万 | 3.6万 | 透支 |
| 共赢系统 | 7.6万 | 4.7万 | 盈余 |
| 稳定专业 | 3.8万 | 2.6万 | 够了 |
| 两年冲刺 | 9.2万 | 4.9万 | 盈余 |
| 双亏内卷 | 1.6万 | 约 0.4万 | 双亏 |
